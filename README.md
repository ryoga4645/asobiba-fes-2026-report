## 🎯 【最新分析】バリュー・パーソナリティ別マッチング傾向ハイライト

ミッションラリー全313接触（12企業 × 58名学生）の確定データを統計分析（ANOVA、Welchのt検定、マン・ホイットニーのU検定、ロジスティック回帰）した結果、**企業と学生の間にある「評価軸の非対称性（すれ違い）」**と**「マッチング成立のゴールデンルール」**が明らかになりました。

詳細レポート: 📄 **[ASOBIBA_FES_バリュー_パーソナリティ分析レポート.md](./ASOBIBA_FES_バリュー_パーソナリティ分析レポート.md)**

```
                    ┌─────────────────────────┐
                    │    企業のアクション     │ ──▶【バリュー重視】
                    │  (理念・社風・本質重視)  │     (p < 0.0001, d = 0.826)
                    └─────────────────────────┘
                                ▲
                                │ 評価軸の非対称性（すれ違いと補完）
                                ▼
                    ┌─────────────────────────┐
                    │    学生のアクション     │ ──▶【パーソナリティ重視】
                    │ (人柄・雰囲気・対面印象) │     (高関心層ほどスコア上昇)
                    └─────────────────────────┘
                                │
                                ▼
          ┌──────────────────────────────────────────────┐
          │      マッチング成立のゴールデンルール        │
          │  バリュー高(≧64)なら パーソナリティ不問で    │
          │  マッチ率 54%〜61%（全体の約1.5倍）に到達！   │
          └──────────────────────────────────────────────┘
```

1. **企業はプロの目で「バリューフィット」を鋭く察知してアクション**:
   - 企業のアクション熱量に応じてバリューフィットが **なし(57.84) ──▶ 知りたい(61.11) ──▶ めっちゃ知りたい(63.79)** と極めて綺麗な単調増加（$p < 0.0001, d = 0.826$）。
   - 一方で企業のパーソナリティフィットには有意差がなく（$p = 0.484$）、企業は人柄ではなく「自社の理念・カルチャーとの適合」を絶対基準にしています。

2. **学生はブース担当者の「パーソナリティフィット」に惹かれてアクション**:
   - 学生のアクションはバリューに差が出ず（$p = 0.262$）、パーソナリティが **なし(78.08) ──▶ 知りたい(79.23) ──▶ めっちゃ知りたい(80.78)** と熱量に比例して上昇（有料企業では 82.44 まで上昇）。
   - 短時間では抽象的な理念を理解しきれず、担当者の「人柄・共感・話しやすさ」で好意を決定しています。

3. **マッチング成立の最強要因（多変量ロジスティック回帰）**:
   - 有料企業バイアスを統制した状態でも、**バリューフィットが1pt上がるごとにマッチ成立オッズが 5.7% 上昇（オッズ比 1.057, $p = 0.0010$）**。10pt高ければオッズは約1.74倍。
   - 有料企業フラグ自体のオッズ比は 1.026（$p = 0.919$）で有意差なし。「有料企業だからマッチした」のではなく「事前に高マッチ学生を割り当てていたからマッチした」という事前の設計意図が立証されました。

4. **3×3マトリクスの黄金ルール**:
   - バリュー高（$\ge 64.0$）のゾーンは、パーソナリティの高低に関わらず **マッチ率 54.1%〜61.2%（全体平均40.9%）** を達成。次回の学生割り当てアルゴリズムの第1優先キーは「バリュー最大化」にすべきです。
